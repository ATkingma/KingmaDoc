# KingmaDoc documentation

KingmaDoc is a feature documentation skill for AI coding agents. It prevents _code
blindness_: `plan` writes a Feature Design Doc before implementation, `verify` writes a
Feature Verification Doc afterwards.

## By task

- **Using KingmaDoc on a project** → [README: Quick start](../README.md#quick-start) and
  [README: Configuration](../README.md#configuration)
- **Using KingmaDoc without installing Python** → the agent skill [`skill/SKILL.md`](../skill/SKILL.md),
  or its generated variants for [Cursor](../skill/cursor.md), [Codex](../skill/codex.md) and
  [GitHub Copilot](../skill/copilot.md)
  ([README: Markdown-only install](../README.md#markdown-only-no-python))
- **Seeing what the output looks like** → [Example plan doc](../examples/verify-mode-plan.md)
- **Contributing code** → [Conventions: Python coding standards](conventions.md#d-python-coding-standards)
  and [Conventions: Architecture](conventions.md#e-architecture-and-object-oriented-design)
- **Changing the generated documents** → [Conventions: Document conventions](conventions.md#b-document-conventions)
  and the template [`templates/plan_default.md.j2`](../templates/plan_default.md.j2)
- **Changing the agent skill** → [`skill/SKILL.md`](../skill/SKILL.md) and [Conventions: Skill conventions](conventions.md#a-skill-conventions);
  keep its output format equal to the template (`tests/test_skill.py` checks this)

## Repository development tooling

Tools for working on this repository. Not part of the KingmaDoc product and not shipped
in the package.

| File | Purpose |
|---|---|
| [`checking-conventions` skill](../.claude/skills/checking-conventions/SKILL.md) | Checks changes against the conventions: automatic checker + manual review workflow |
| [`.claude/settings.json`](../.claude/settings.json) | Stop hook that runs the convention checker after every agent turn |
| [`scripts/build_skill_variants.py`](../scripts/build_skill_variants.py) | Generates the Cursor, Codex and Copilot skill variants from `skill/SKILL.md` |
| [`.github/workflows/ci.yml`](../.github/workflows/ci.yml) | CI: pytest on Python 3.11–3.13, Linux/macOS/Windows, plus a CLI smoke test |
