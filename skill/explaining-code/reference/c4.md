# Format: C4 (compact)

Contents: In short · Terms (optional) · Context · Containers · Components · How it works
· Routes and permissions (optional) · Data (optional) · Configuration (optional) · What
changed (branch only) · Design choices (optional) · Where to find what · Couldn't work
out (optional, at most three).

Used when `.featuredoc.yml` has `explain: {format: c4}`, or when the user asks for a
compact explainer. It zooms in step by step (context, containers, components, flows,
data) and decodes every figure with a table. Follow the rules in `../SKILL.md`; draw the
C4 figures as [c4-model.md](c4-model.md) says and the others (sequence, ER, state
machine …) as [models.md](models.md) says, adding a model's figure under "How it works"
or "Data" when its signal is in the code.

Text in `<angle brackets>` is filled in.
